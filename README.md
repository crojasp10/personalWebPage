# Meridiano

CV de desarrollador en Angular, en español e inglés. El texto que ves es de ejemplo.

## Verlo

```bash
npm start
```

Abre http://localhost:4200/

## Cambiar el contenido

Todo el texto, los enlaces y los datos viven en `src/app/cv.ts`.

- `person` — nombre, iniciales y correo
- `railLinks` — GitHub, LinkedIn, sitio y correo
- `jobs` — empresas
- `pieces` — proyectos, año y enlaces de demo y código
- `es` / `en` — los textos de cada idioma

## Compilar

```bash
npm run build
```
